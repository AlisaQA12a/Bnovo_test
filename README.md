Тестовое задание для компании Bnovo  на позицию AQA Python Junior

Произведено тестирование API модуля бронирования https://docs.google.com/document/d/135jObE7uKuBdiUYyU1_ySoNUCzIbnIV-yrjeuj9zOXo/edit?tab=t.0#heading=h.628phil8unj9

 Общие проверки для всех API: 
     1.Проверка кода ответа (200 OK для успешных запросов, 4xx/5xx для ошибок).
     2.Проверка структуры JSON-ответа (наличие обязательных полей).
     3.Валидация типов данных в ответе (например, account_id должен быть int, name — string).
     4.Проверка обработки невалидных запросов (например, отсутствие обязательных параметров).

 Специфичные проверки для каждого API
   Мета-информация об отеле
     1.Проверка, что возвращаются корректные данные отеля (название, адрес, контакты).
     2.Проверка поля hotel_type (должен содержать допустимые значения: hotel, apartments и т.д.).
   Категории номеров
     1.Проверка, что для каждой категории номеров возвращаются:
       id, name, description.
     2.Корректные данные о вместимости (adults, children).
     3.Список фотографий (если photos не null).
     4.Проверка локализации (name_ru, name_en и т.д.).
   Тарифы
     1.Проверка, что тарифы содержат:
       id, name, description.
     2.Корректные данные о предоплате (booking_guarantee_sum, booking_guarantee_unit).
     3.Правила отмены (cancellation_rules, cancellation_deadline)

Сгенерирован Allure-отчет.

В процессе тестирования найдены ошибки:
  1. Отсутсвие обязательного параметра в теле запроса соответсвует код ошибки 400, а  возвращается код 406.
  2. При передаче в тело запроса в параметр account_id спец симоволов и латинских букв типом данных string возвращается ошибка 500 вместо 404
  3. Передача пустой строки в обязательные параметры account_id и uid в теле запроса соответствует код ошибки 404, а возвращается 406
